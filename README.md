# Chemiation · 化学反应原理机理空间推演工坊 (ReactionPrinciple)

> **Chemiation** 是一个基于纯原生 2D Canvas 与空间伪 3D（Pseudo-3D）纵深映射的**高保真化学反应原理与微观机理推演工坊**。专注于直观呈现分子靠近、过渡态中间体、化学键断裂/重组、质子迁移及高分子聚合的全流程空间动态推演。

---

## 🌟 核心特性

1. **纯推演渲染器定位 (Pure Deduction Renderer)**：
   - 聚焦化学微观反应机理的高保真自动演化，无需繁琐的手动摆放。
   - 基于原生 2D Canvas 拟态空间伪 3D 渲染引擎，支持鼠标左键 360° 自由旋转、滚轮多级平滑缩放与一键视角复位。

2. **极简宣纸底色与纯字母学术排印 (Academic Letter Typography · No Spheres)**：
   - 放弃传统笨重的实体小球模型，全量采用 `Century Gothic` 高雅学术纯字母排印。
   - 化学键线在元素符号外轮廓精准自动修剪（Clip Radius），并辅以柔和透空描边，高密度键网亦层次分明。

3. **化学键双向空间深度色阶与能量动态 (Bond Gradients & Kinetic Animation)**：
   - 化学键沿键向由两端原子各自的空间深度色阶平滑线性过渡，前后景深立体感逼真。
   - **中心开裂消解**：化学键断裂时呈现自中间向两端收缩裂解的琥珀赭红色光晕渐变。
   - **高能键迁移与合成**：断裂键伴随电子对沿空间平滑弧线迁移至目标原子重构成键。

4. **全流程元素与氢原子严格守恒 (Strict Mass & Hydrogen Conservation)**：
   - 彻底解决传统演示中氢原子突兀消失或单原子游离悬空问题。
   - 从始态底物、关键过渡态中间体到终步产物，全程严谨追踪全体系每一个原子。

5. **高分子聚合物大括号规范与智能就近延伸键 (Polymer Brackets `[ ]ₙ` & Smart Nearest-Side Extension)**：
   - **高分子微光保护区**：精准计算聚合物骨架包围盒，渲染极淡暖色聚合物保护区与学术中括号 `[ ]`。
   - **智能视差自适应（左右就近延伸）**：
     - 在 3D 视角自由旋转或缩放时，引擎按投影屏幕坐标动态升序排序聚合端点；
     - 投影偏左的端点自动匹配左括号向左穿出，投影偏右的端点自动匹配右括号向右穿出；
     - 始终保持“就近延伸”，彻底消除视角反转或侧视时键线横穿整个分子的交叉错位。
   - **立体开链延伸表达**：前半段为坚挺实线并在括号穿透处呈现立体锚固节点，后半段为开链虚线延伸至链端微点，生动体现高分子链节无限延伸。
   - **智能排除小分子**：自动识别并排除副产物小分子（如缩合脱除的水分子），保持聚合物重复单元严谨纯粹。
   - **学术聚合排印**：支持 Century Gothic 粗斜体聚合度下标（如 `[ ]ₙ`）及顶部微型学术胶囊标签。

6. **AnyChem 风格右置工作区 + 自研 ACPL 脚本引擎 (Reaction Script Engine)**：
   - **可调宽度侧边栏**：支持边缘鼠标拖动自由调节工作区宽度（320px ～ 760px），支持一键折叠收起。
   - **自研极简 ACPL 脚本**：无需手动填写 $(x, y, z)$ 三维坐标，支持力导向空间排布，可实时编辑脚本并一键运行推演。
   - **丰富的机理预设与模板库**：
     - 乙酸与乙醇费歇尔酯化机理
     - 中科院 ASAP 二氧化碳人工全合成淀粉完整路线 (CO₂ → C₁ → C₃ → C₆ → 直链淀粉)
     - 甲烷自由基光解氯代机理
     - 二氧化碳催化加氢制甲醇机理
     - 哈伯-博施法工业合成氨机理

## 🧪 模块与架构

| 模块文件 | 定位与职能 |
| :--- | :--- |
| [`index.html`](index.html) / [`reaction.html`](reaction.html) | 主应用入口，包含 2D Canvas 拟态空间伪 3D 视口与右侧推演工作区 |
| [`css/reaction.css`](css/reaction.css) | 极简淡黄宣纸视觉风格、工作区交互布局与时间轴轨道样式 |
| [`js/reaction/pseudo3DRenderer.js`](js/reaction/pseudo3DRenderer.js) | 空间伪 3D 投影算法、景深色阶、断键/成键/迁移及聚合物大括号智能就近渲染引擎 |
| [`js/reaction/reactionData.js`](js/reaction/reactionData.js) | IUPAC 元素质量数据、严谨化学机理分步步骤、原子三维坐标与聚合物拓扑数据集 |
| [`js/reaction/scriptParser.js`](js/reaction/scriptParser.js) | 自研 ACPL (Reaction Script) 词法语法解析器、自动空间排布与序列化生成器 |
| [`js/reaction/reactionApp.js`](js/reaction/reactionApp.js) | 反应推演控制器、步骤时序轨道播放/步进驱动与全端事件交互中枢 |

## 🚀 运行方式

本项目为纯前端静态 Web 应用，无须任何编译打包构建工具：

1. **直接双击** 打开目录下的 [`index.html`](index.html)（或 [`reaction.html`](reaction.html)），即可在现代浏览器中直接运行。
2. 或使用本地静态服务器体验：
   ```bash
   npx serve .
   # 或
   python -m http.server 8080
   ```
3. 部署到 GitHub Pages 时，可直接作为静态站点部署访问。
