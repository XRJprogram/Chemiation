# Chemiation · 量子原子与电子动力学视界 (AtomScope)

> **Chemiation** 是一个专注于化学与微观物理交互可视化动画的项目集合。本项目为其中的核心子项目 —— **单元素动态电子轨道与量子几率云 3D 仿真视界**。

---

## 🌟 核心特性

1. **3D 动力学原子模型（基于 Three.js WebGL）**：
   - **微观涨落原子核**：根据质子数与中子数生成空间密集紧致核心，带有量子布朗涨落与脉冲能量光晕。
   - **多层电子流光运转**：按开普勒/玻尔轨道频率模拟内快外慢的电子运动，每个电子均携带高斯渐变流光拖尾（Comet Trails）。
   - **3 种三维观测模式一键切换**：
     - **3D 天体陀螺模式 (Gyroscopic)**：多轴立体交错天体仪排布，极具未来科幻张力。
     - **经典玻尔平面模式 (Bohr Flat)**：共面同心圆分布，清晰直观地观察与对比各层电子数。
     - **量子几率云模式 (Quantum Probability Cloud)**：数千个弥散光子粒子，真实再现薛定谔波函数径向几率密度。

2. **IUPAC 标准 118 全元素周期表集成**：
   - 收录全部 118 个元素完整的科学理化数据（包含镧系与锕系）。
   - 包含科学准确的各能级主量子数电子排布（K、L、M、N、O、P、Q）、基态电子构型（如 [Ar] 3d⁶ 4s²）、相对原子质量、价电子数、电负性与物态。
   - 动态分类筛选（活泼非金属、碱金属、碱土金属、过渡金属、卤素、稀有气体等）与全局拼音/符号实时搜索。

3. **未来感 Glassmorphism 科学 HUD 档案面板**：
   - 实时显示当前元素的符号、大字中文名、汉语拼音、英文全名及周期/族信息。
   - 各层电子分布（K-Q）动态能量柱状图，直观标记价电子层。

4. **纯原生 Web Audio API 合成音效**：
   - 无需外置音频文件依赖，纯原生振荡器生成柔和的高科技微交互音效。

5. **全端交互与键盘快捷键**：
   - 支持鼠标左键 360° 自由旋转、滚轮多级缩放、右键平移。
   - ← / →：上一个 / 下一个元素快捷步进。
   - Space（空格键）：暂停 / 继续运转。
   - 支持速度调节滑块（0.2x ~ 2.5x）与视角快速复位。

## 🌟 模块二：化学反应机理推演 (ReactionPrinciple)

1. **纯推演渲染器定位 (Pure Deduction Renderer)**：
   - 聚焦高保真化学机理展示与自动推演，用户无需繁琐手动位移原子。
   - 支持鼠标左键 360° 空间旋转、滚轮多级缩放、双指捏合与一键复位。
2. **化学键线性深度渐变 (Bond Gradients)**：
   - 化学键沿键向由两端原子各自的空间深度色阶平滑线性过渡，空间前后纵深立体感倍增。
   - 断裂键呈现琥珀赭红消解渐变，生成键呈现高能金橙生长渐变。
3. **氢原子全流程严格守恒 (Strict Hydrogen Conservation)**：
   - 彻底修复各步骤反应中氢原子突兀消失的问题，全程严谨追踪反应物、中间体、离去基团与终产物的每个氢原子。
4. **AnyChem 风格推演工作区右置 + 极简上手脚本**：
   - **工作区右置**：支持边缘鼠标拖动自由调节工作区宽度（320px ～ 760px）与一键折叠收起。
   - **极简 ACPL 脚本**：无需用户手动计算与填写三维 $(x, y, z)$ 坐标，引擎支持力导向自动空间排布；配备一键模板快捷插入（酯化、氯代、合成氨、CO₂加氢）。
5. **纯字母排印 · 绝无球体 (No Spheres)**：
   - 所有元素均采用高雅学术衬线字体（如 `Cinzel` / `Times New Roman`）纯字母呈现，键线在字符外轮廓处自动精准修剪。

## 🚀 运行方式

本项目为纯前端静态 Web 应用，无任何构建打包门槛：
1. **直接双击** 打开目录下的 `index.html`（3D 电子视界）或 `reaction.html`（化学反应原理推演），即可在现代浏览器中直接运行体验。
2. 或使用本地静态服务器：
   ```bash
   npx serve .
   # 或
   python -m http.server 8080
   ```
3. 托管于 GitHub Pages 时，可直接作为静态站点部署访问。
