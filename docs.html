ACPL 反应机理推演脚本语法手册

Antigravity & Chemiation Chemical Principle Language · 面向化学机理推演的极简声明式脚本规范

1. 设计理念与概述

ACPL (Antigravity Chemical Principle Language) 是 Chemiation 专为化学反应机理、过渡态演化与聚合物推演设计的极简 DSL 语法。其核心原则包括：

  • 极简可读：去除冗余标点，采用自然声明式语法，无需编写繁重的 JSON 或代码。
  • 智能空间排布：用户无需手算三维空间坐标，声明原子和键后，引擎内置力导向算法自动解算空间立体构型。
  • 严格质量守恒：支持多基元步骤连续推演，消除“游离原子”悬空等非物理现象。
  • 纯粹机理导向：已全面精简冗余项（如移除旧版 deltaH 与繁琐动作标签等），专注电子转移、键的断裂与重组过程。

2. 全局反应元数据声明

脚本头部必须包含或选择性声明反应的整体属性：

# 反应全称（必填）
reaction "乙酸与乙醇费歇尔酯化反应"

# 化学反应总方程式（必填）
equation "CH₃COOH + CH₃CH₂OH ⇌ CH₃COOCH₂CH₃ + H₂O"

# 反应分类标签（可选）
category "经典有机机理"

# 机理概述与背景说明（可选）
summary "经典亲核酰基取代：底物靠近、亲核加成生成四面体中间体、脱水消除生成乙酸乙酯与水。"

3. 基元反应步骤 (Step Block)

每一个基元步骤使用 step "步骤名称" { ... } 代码块进行包裹：

step "1. 反应物底物吸附与碰撞" {
  # 步骤原理阐释说明
  note "乙酸与乙醇分子受热靠近，羟基氧原子准备进攻羰基碳原子。"

  # 原子声明
  atom C1 C -2.0 0.0 0.0
  atom O1 O -1.5 1.2 0.0
  
  # 化学键声明
  bond C1 O1 2
}

4. 原子与化学键拓扑定义

4.1 原子定义 (atom)

支持以下两种语法：

语法格式 说明 适用场景
atom <ID> <Element> <X> <Y> <Z> 显式指定原子的三维空间相对坐标 需要精准空间取向或精密对称性排布时
atom <ID> <Element> 不提供坐标，由引擎自动力导向立体排布 快速草拟反应、自动计算分子空间结构时

4.2 化学键定义 (bond)

语法：bond <原子ID1> <原子ID2> [键级]

  • bond C1 C2 1：在 C1 与 C2 之间建立单键（默认）。
  • bond C1 O1 2：在 C1 与 O1 之间建立双键（如羰基 C=O）。
  • bond N1 N2 3：在 N1 与 N2 之间建立三键（如氮气分子 N≡N）。
💡 提示： 渲染器会自动根据两个原子的元素类型，在键上绘制平滑的双向渐变色与纵深光影，不同元素原子之间一目了然。

5. 高分子聚合物与大括号规范 (Polymer)

在聚合反应机理步骤中，可通过 polymer 语句开启聚合物大括号视图：

# 语法：polymer "<下标>" ["说明文字"] [exclude "<排除原子ID...>"]
polymer "n" "直链淀粉单体最简重复单元 · [C₆H₁₀O₅]ₙ" exclude "Ow Hw1 Hw2"

核心机制与设计考量：

  • 单体最简重复单元原则：例如淀粉生成过程，严谨表示为吡喃葡萄糖单环脱水脱氧后的最简 $[C_6H_{10}O_5]_n$ 单元，结构纯粹简明。
  • 动态就近延申截断机制：当视角拖拽旋转时，系统在每一帧动态计算大括号左侧与右侧的就近截断点，使化学键始终向左右就近延申至括号外，彻底解决跨视角“远距离交叉飞线”的视觉 Bug。
  • 排除独立副产物 (exclude)：缩聚反应常伴随脱除水分子等小分子副产物，使用 exclude "Ow Hw1 Hw2" 可将副产物原子移至大括号外侧独立展示。
