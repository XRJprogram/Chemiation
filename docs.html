CCPL 反应机理推演脚本语法手册

Chemiation Chemical Principle Language · 面向化学机理推演的极简脚本

1. 设计理念与概述

CCPL (Chemiation Chemical Principle Language) 是 Chemiation 专为化学反应机理设计的极简 DSL 语法。其核心原则包括：

  • 极简可读：采用自然声明式语法，无需编写繁重的 JSON 或复杂代码。
  • 自动空间排布：无需手动计算三维空间坐标，仅声明原子与化学键拓扑后，由排布算法自动解算分子的三维空间构型。
  • 严格质量守恒：支持多基元步骤连续推演，消除“游离原子”悬空等非物理现象。
  • 纯粹机理导向：专注键的断裂与重组过程。

2. 全局反应元数据声明

脚本头部必须包含或选择性声明反应的整体属性：

# 反应全称（必填）
reaction "乙酸与乙醇费歇尔酯化反应"

# 化学反应总方程式（必填，支持自然键盘输入 -> 或 <=>，底层自动格式化为 → 与 ⇌）
equation "CH_3COOH + CH_3CH_2OH <=> CH_3COOCH_2CH_3 + H_2O"

# 机理概述与背景说明（可选）
summary "经典亲核酰基取代：底物靠近、亲核加成生成四面体中间体、脱水消除生成乙酸乙酯与水。"
💡 上下标与化学式符号排印： 编写方程式、机理概述或步骤说明时，无需手动输入 Unicode 下标字符：
  • 化学式数字自动下标：元素符号或括号后跟随的普通数字（如 CH3COOH、H2O、CO2、C6H12O6）会自动解析排印为下标 CH₃COOH、H₂O、CO₂、C₆H₁₂O₆。
  • 显式下标语法：支持 _2 或 _{10}、_n 等语法（如 H_2O → H₂O，[C6H10O5]_n → [C₆H₁₀O₅]ₙ）。
  • 显式上标语法：支持 ^2、^{2+}、^+、^- 等离子价态标记（如 Fe^{3+} → Fe³⁺）。
  • 反应箭头简写：直接键入 -> 或 --> 会自动规整为 →，键入 <=> 或 == 会自动规整为可逆双向平衡箭头 ⇌，键入 <-> 为共振箭头 ↔。

3. 基元反应步骤 (Step Block)

每一个基元步骤使用 step "步骤名称" { ... } 代码块进行包裹。步骤无需手动填写序号（如 1. / 2.），Chemiation 引擎会自动按书写顺序编排编号：

step "反应物底物吸附与碰撞" {
  # 步骤原理阐释说明
  note "乙酸与乙醇分子受热靠近，羟基氧原子准备进攻羰基碳原子。"

  # 原子声明
  atom C1 C -2.0 0.0 0.0
  atom O1 O -1.5 1.2 0.0
  
  # 化学键声明
  bond C1 O1 2
}
提示： 无需手动书写步骤序号，即使脚本中带有序号，也会重新按顺序动态编号。

4. 原子与化学键拓扑定义

4.1 原子定义 (atom)

支持以下两种语法：

语法格式 说明 适用场景
atom <ID> <Element> <X> <Y> <Z> 显式指定原子的三维空间相对坐标 需要精准空间取向或精密对称性排布时
atom <ID> <Element> 不提供坐标，由引擎自动力导向立体排布 快速草拟反应、自动计算分子空间结构时（参见预设中的狄尔斯-阿尔德加成样例）

4.2 化学键定义 (bond)

语法：bond <原子ID1> <原子ID2> [键级]

  • bond C1 C2 1：在 C1 与 C2 之间建立单键（默认）。
  • bond C1 C2 1.5：在 C1 与 C2 之间建立芳香键 / 共振离域键（键级 1.5，一侧实线一侧虚线呈现）。
  • bond C1 O1 2：在 C1 与 O1 之间建立双键（如羰基 C=O）。
  • bond N1 N2 3：在 N1 与 N2 之间建立三键（如氮气分子 N≡N）。
💡 提示： 渲染器会自动根据两个原子的元素类型，在键上绘制平滑的双向渐变色与纵深光影，不同元素原子之间一目了然。

4.3 自由基单电子 (radical) 与形式电荷 (charge)

在有机化学反应机理推演中，自由基、碳正/碳负离子与过渡态电荷中心的严谨表达至关重要：

  • 自由基中心 (radical)：标注单电子自由基（如氯原子自由基 Cl·、甲基自由基 ·CH3），将在原子右上角渲染出高对比度实心圆点（·）。
    语法一（行内声明）：atom C1 C -1.8 0 0 radical
    语法二（独立声明）：radical C1 Cl2
  • 形式电荷 (charge)：针对离子与过度成键/少键原子（如氧鎓阳离子 O+、烷氧负离子 O−、碳正离子 C+），将在原子右上角渲染出圈加/圈减徽章（⊕ 或 ⊖）。
    语法一（行内声明）：atom O1 O -1.4 1.1 0 charge=-1、atom O2 O -1.0 -1.3 0 charge=+1
    语法二（独立声明）：charge O1 -1、charge O2 +1
  • 高分子聚合物电荷隐匿抑制：当原子被聚合物大括号 polymer 囊括进入重复单元时，系统会自动抑制其反应性电荷与单电子标记，体现化学键封闭与中和规范。

4.4 芳香烃与大 Π 键规范 (aromatic，可选)

在芳香烃或共轭环系步骤中，大 Π 键展示为完全可选特性。通过在步骤块内加入 aromatic（或简写 pi）声明，渲染器将在三维空间中呈现出经典的芳香内切虚线环与上下离域 π 电子云轨道：

# 语法：aromatic "<环原子ID列表...>" [tag "<学术标签说明>"]
aromatic "C1 C2 C3 C4 C5 C6" tag "Π_6^6"
  • 可选性设计：若步骤中不包含 aromatic 声明，系统仍可正常使用标准键级（如 1.5 或单双键交替）显示；仅在显式声明时开启离域大 Π 键空间投影。
  • 真实三维空间投影：自动根据环上原子三维坐标解算环平面的质心与法向量，在环平面内切绘制经典 Robinson 虚线环，并在分子平面上下 $\pm 0.38\text{ \AA}$ 处投影呈现半透明离域 $\pi$ 电子云轨道面与共轭轨道虚线。
  • 跨步骤动态生灭：在反应机理中，若大 Π 键在亲电加成中被破坏形成 Wheland 碳正离子中间体，并在脱质子后重新芳构化，大 Π 键电子云将在步骤切换过程中自然淡出与淡入。

4.5 隐式氢缩略与自动共价补全 (Implicit Hydrogens)

在推演有机化学反应机理时，分子骨架上的氢原子繁多。CCPL 支持隐式氢缩略书写。在定义原子拓扑时，您可以只声明碳骨架或杂原子骨架，引擎会根据元素标准共价规则、形式电荷（charge）以及自由基单电子（radical）自动计算并补全缺失的氢原子与共价单键：

元素族类别 基准成键数 电荷与自由基修正规则 典型示例
碳族元素 (C, Si, Ge) 4 4 - |charge| - radical - 已有键级和 中性 C 补足 4 键；碳正离子 C+ 补足 3 键；甲基自由基 C· 补足 3 个单键。
氮族元素 (N, P, As) 3 3 + charge - radical - 已有键级和 (P 支持超价) 中性胺 N 补足 3 键；季铵阳离子 N+ 补足 4 键；酰胺负离子 N- 补足 2 键。
氧族元素 (O, S, Se, Te) 2 2 + charge - radical - 已有键级和 (S 支持超价) 中性 O 补足 2 键；氧鎓正离子 O+ 补足 3 键；烷氧负离子 O- 补足 1 键。
卤素族 (F, Cl, Br, I) 1 max(0, 1 + charge - radical - 已有键级和) 中性卤素 1 键；卤鎓阳离子 Br+ 补足 2 键。
硼族 (B) 3 3 - charge - radical - 已有键级和 中性 B 补足 3 键；四配位硼酸根负离子 B- 补足 4 键。
金属与稀有气体 0 不补加隐式氢原子 Fe, Cu, Pd, Pt, Na, Mg 等金属原子保持用户自定义配位结构。

隐式氢控制指令与修饰词：

  • hydrogens <auto|none|explicit>：步骤或全局指令。默认状态为 auto；若设为 none 或 explicit，则关闭当前步骤的自动补氢。
  • atom <ID> <Element> explicit（或 noImplicitH）：针对单个原子显式抑制补氢，保留未饱和孤对电子或裸露位点。
💡 编辑器工具栏「补全 H」： 在推演工坊工具栏中点击「补全 H」按钮（或使用快捷键 Alt + H），可将编辑器中的 CCPL 脚本一键展开为显式声明的氢原子与 bond 单键代码，便于在显式脚本基础上进一步调整特定氢原子的质子转移或空间位阻。

5. 高分子聚合物与大括号规范 (Polymer)

在聚合反应机理步骤中，可通过 polymer 语句开启聚合物大括号视图：

# 语法：polymer "<下标>" ["说明文字"] [include "<包含单元原子ID...>" | exclude "<排除副产物原子ID...>"] (二选一)
polymer "n" "直链淀粉单体最简重复单元 · [C_6H_{10}O_5]_n" include "C1 C2 C3 C4 C5 C6 O2 O3 O5 O6"

核心机制与语法说明：

  • 包含指定单元 (include) 与排除副产物 (exclude)：支持通过 include 明确框选聚合单元内的骨架原子，或通过 exclude 排除脱水缩合产生的离去小分子（二选一即可，如 exclude "Ow Hw1 Hw2"）。

您可以在推演工坊编辑器的快捷模板栏中一键插入以下标准机理骨架：

模板按钮 机理类型 包含特性
+ 步骤 通用基元步骤 带注释的标准 atom 与 bond 骨架
加成消除 亲电加成/消除反应 碳碳双键解离、卤素/亲电进攻形成饱和中间体
配位催化 金属络合催化循环 中心金属原子多重配位活化底物靶键
自由基 均裂引发与链传递 单电子夺氢、甲基自由基偶联机理
