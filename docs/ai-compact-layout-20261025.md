## 立即体验

在项目根目录运行 `npm run preview:studio`，打开终端显示的 `http://127.0.0.1:31821/experience`。

1. 点页面上方“开始完整体验”，会新建一段对话并发送 SN2 示例需求。
2. 在问题表单选择基础教学或详细讲解，可自由补充后提交。
3. 观察左侧随完整步骤逐步更新；等待结束后可对比原稿、撤回或保留此版本。
4. 保留后可播放、刷新恢复，再点“只完善本步”体验指定步骤的说明修改。

页面明确标注“本地示例 · 固定 SN2 响应，未调用真实模型”。它使用同一套正式对话、请求、流式解析、校验、动画和版本功能，回复源是单独的本地固定示例，不代表模型生成能力或专业化学审核。示例中的背面接近为展示构型，不标为稳定中间体。

“使用真实模型”恢复浏览器原有模型读取方法并打开设置。演示配置仅在当前页面内存中，不写入或读取真实密钥进行示例请求。同一标签刷新保持当前模式；也可用 `?mode=real` 或 `?mode=demo` 明确进入。页面上方始终标明当前模式，不会自动发送模型请求。

真实模式下，先保存自己的接口配置，再点“测试真实模型完整流程”：新建对话并发送苯乙烯溴加成测试需求；如检索到相似机理，点“根据我的要求重新推演”进入新生成。模型应先返回教学深度问题，选择或自由补充后继续生成，通过基础检查的完整步骤逐步进入左侧动画。最后由用户对比、撤回或保留版本。缺少配置时先打开设置，不静默退回固定示例。

同端口 `/` 是普通项目入口，不注入演示脚本。普通 `server.bat` 也没有这些演示路由。

预览服务仅监听回环地址，使用 `NODE_ENV=test` 和独立临时数据目录；不连接正式 Upstash 数据库。默认端口可通过 `CHEMIATION_PREVIEW_PORT` 指定。关闭启动该命令的进程即可停止；聊天草稿仍属于该浏览器与来源的 IndexedDB。
