# AI 标准流程实现与聊天空间预览（2026-10-25）

后续更新：用户确认效果图后，紧凑界面已在原项目落地；以下保留流程实现阶段记录。最新布局与运行入口见 [AI 对话紧凑界面与本地体验](ai-compact-layout-20261025.md)。

## 本轮交付

本轮在现有项目上实现标准流程的核心运行逻辑；界面压缩方案单独制作 HTML 与 PNG 预览，未将新布局覆盖进项目。沿用当前 AI 请求、原有问题表单、动画、版本和 Upstash 存储，不增加运行依赖、独立规划服务或每轮固定的额外模型请求。

## 已实现的流程

1. **识别任务。** 区分新生成、完善、修错、仅解释。只问“为什么”时支持直接文字解释，不再强制生成脚本或追加问题。
2. **程序先处理明显缺项。** “生成一个酯化反应”等明显缺少对象的请求，先显示具体反应物问题；“优化一下”等没有明确目标的请求，先询问说明、布局还是结构。使用原有问题卡片，不需要配置模型即可回答这些本地问题。
3. **记录回答并继续原任务。** 保存原请求、任务类型、用户回答原文、问题字段、待答问题、轮数和阶段。回答后继续原任务，避免把新建机理的补充条件误识别为修改旧脚本。不同的通用条件问答分别保留，明确更改某一字段时更新该字段。
4. **信息足够时执行。** 不强制每个反应填写完整实验参数，不固定多问一次教学深度或“是否开始”。更具体的底物歧义、必要条件和路径判断仍由模型结合原文判断；提示中明确禁止猜测和重复询问。
5. **保护修改范围。** “只修改第 2 步”等明确编号可直接建立程序范围；无效编号阻止发送。仅改说明时，程序检查 CCPL/JSON 中除说明外的内容；发现结构、坐标、步骤名等变化，会进入原有有限纠错。仅改布局时保护化学结构和其他说明。最终应用前再次检查这些约束。
6. **保持原生成保护。** 继续流式接收、完整步骤预览、整份基础检查、最多追加两次纠错、共享超时预算、显式保留和原稿冲突拦截。流式预览也核对本轮修改约束；语法可用但越界的步骤不会进入临时动画。
7. **保存中断和重试依据。** 发起模型请求前保存请求快照。刷新关闭后重新打开，会标明上次请求中断，保留已确认信息及原请求、源稿、范围，供安全重试；不会宣称后台仍在生成。
8. **阻止完全相同的重复提问。** 若模型重新询问已回答的同一问题，本轮停止并保留回答和重试入口。该判断针对规范化后的同文问题，不声称已实现所有语义改写的去重。
9. **已有机理作为参考。** 名称或关键词命中不会仅凭同名和审核标记自动采用；仍展示来源与预览选择。条件一致性尚未由结构化检索证明。

## 运行状态和保存格式

新增 `js/aiWorkflow.js`，提供不依赖 DOM/网络的任务识别、预检、回答记录、提问检查、输出约束和解释响应处理。`aiStudio.js` 调度现有交互，`aiAssistant.js` 继续执行原调用与检查管线。

会话增加可选 `workflow` 与 `activeGeneration`；失败重试与脚本版本可记录所属任务。任务记录只接受白名单字段，来源为用户的回答原文，不把模型猜测记作用户确认。问题可选带 `field` 来关联条件。旧记录缺少这些字段仍可读取，旧问题表单可初始化本轮任务后继续回答。

沿用已有会话 JSON、相同 IndexedDB 和 Upstash 键，不需要手工建表或迁移。**部署必须同时包含 `js/aiWorkflow.js`、`js/aiStudioCore.js` 和新的前端脚本**；服务端的共享核心会引用新流程模块。不能只复制旧 `server/` 文件夹。客户端会检查云端是否完整保留任务字段，不完整时保留本机副本并提示更新。

## 验证与边界

- AI 自动回归：165 项通过，包含新增流程、条件持久化、任务切换、仅解释、说明/布局约束，以及越界输出纠错和应用前复查。
- 原服务端集成：23 项通过；会话存储：15 项通过，增加任务在 HTTP 与 Upstash REST 模拟传输中的保留检查。
- 真实 Chrome：41 个场景通过，模拟模型共 30 次请求；包含新建缺项补问、任务刷新恢复、回答后直接生成与动画预览、修改目标补问、自然语言指定步骤、直接解释、重复问题阻止、流式中刷新后按原请求重试。
- 原包解析与导出校验通过。静态构建按原流程执行。

上述测试使用临时目录与临时账号，模型及 Upstash 采用模拟服务，未调用真实付费模型或修改生产数据库。

当前本地预检是保守规则，覆盖明显含糊的输入，不是完整的自然语言化学理解器；复杂结构、条件冲突和需求覆盖仍需要模型与专业审核。专业机理正确性、模板条件一致性、所有语义重复问题的识别、真实模型成功率没有因此被证明。规范中的目标与已实现范围应继续区分。

标准定义见 [标准流程 V1](ai-script-workflow-v1.md)，运行方式仍为原有 `server.bat` / `npm start`。本轮未推送 GitHub 或部署。
