本地服务器系统架构与环境

Chemiation 采用全栈自主可控的微架构，服务端完全基于 Node.js 标准库实现，不依赖外部大型关系型数据库或复杂的云设施， 通过轻量级原子化 JSON 事务引擎保证在任何机器上均可作为本地独立服务器即开即用。

数据存储持久化路径

  • server/data/users.json (用户账号与安全哈希)
  • server/data/reactions.json (推演机理与CCPL脚本库)
  • server/data/logs.json (服务器审计日志流水)
  • server/data/session.secret (HMAC 秘钥安全文件)

安全加密机制

  • PBKDF2 SHA-512 (100,000 次哈希迭代 + 随机加盐)
  • HMAC-SHA256 签名会话令牌 (JWT 规范，7天有效)
  • 常数时间比对算法 (防止时间差侧信道攻击)
  • 路径穿越防护与 10MB 请求负载熔断
